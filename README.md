# 全景平台 · 公开脱敏源码

这是本地项目的公开源码快照，不是当前生产服务器的完整备份，也不是已验收的生产部署包。

保留前后端、共享规则、测试和开发脚本。生产凭据、环境文件、证书、业务账本、知识库资料、现场图片和业务报表没有上传。代码中已有的真实人员、应用标识及部署地址已替换为示例；设备阈值种子保留结构并清空实际记录。

## 开发准备

安装 Node.js 22 或更新版本；运行 `npm ci`。复制 `.env.example` 为 `.env`，填写你自己的应用凭据与数据源，再运行 `npm run dev`。使用 Python 附属功能时，按相应 `tools` 目录的依赖说明准备 Python 环境。

部分功能需要自行提供业务数据、阈值数据、页面图片、会议模板及月报模板。公开副本中的示例标识不能用于连接原生产环境。

## 验证边界

本仓库不包含便携运行时、node_modules、dist 或旧 Git 历史。源码检查通过不代表真实飞书、数据库、对象存储、审批消息或全部业务流程已验证。请在独立环境验证后再决定部署。

请勿把 `.env`、证书、私钥、访问令牌、个人信息或业务导出文件提交到本仓库。
