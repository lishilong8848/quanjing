# XJ-1180 与 CG261021-602 只读诊断

在正在运行系统的服务器上解压到应用目录外，例如桌面独立文件夹，双击 `COLLECT-APPROVAL-LATENCY.cmd`。输入实际应用目录；默认目录正确时直接回车。完成后把同目录生成的 `approval-latency-diagnostics-*.json` 发回当前会话。

这是只读诊断工具，不是热包。无需停服或开启本地回调，不重新审批，不执行任务，不发消息，不联网，不修改系统文件。只在工具所在目录创建一份新的诊断 JSON。

内容限于两笔已确认记录的状态、任务时间、错误代码、账本大小/数量、脱敏日志摘要和现有休假受理耗时。不会导出原始日志、申请正文、姓名、人员 Open ID、附件、配置值、token 或任意业务 payload。

读取配置仅用于定位账本候选路径，不等于确认正在运行的进程实际环境。安装回执只记录版本元数据，不代替现场完整指纹校验。日志最多完整读取每份 128 MiB，超过时只取最后 8 MiB，并明确标记覆盖不足；不扫描轮转日志。账本最多 32 MiB，超过时标为不完整，不修改或截断账本。

休假日志有 prepareMs/commitMs/totalMs 时原样提取整数；没有记录的历史耗时不会推算。采购旧版没有分段耗时，任务时间不能代替实际提交耗时。工具自身读取、哈希和 PowerShell 解析耗时也不能作为 Node 回调耗时。

退出码 0 表示两笔账本目标均找到；2 表示部分证据缺失，仍应回传生成的报告；1 表示路径安全检查或执行失败，请保留错误代码。不要为采集而重复提交申请。
